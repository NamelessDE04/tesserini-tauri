# Tesserini Tauri

Web app per creare i tesserini di riconoscimento di ASD Tauri Softair (88 × 140 mm, un solo lato con i brevetti).

- Il codice è nella cartella `web/`.
- A ogni modifica su `main` GitHub la pubblica in automatico su Firebase Hosting:
  https://tesserini-tauri.web.app
- Accesso con Google e archivio condiviso su Firebase (progetto `tesserini-tauri`).
- Le regole di sicurezza del database sono in `firestore.rules` (da copiare in Firebase → Firestore → Regole).
